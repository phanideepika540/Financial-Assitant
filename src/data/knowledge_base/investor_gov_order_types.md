# Types of Orders

An order tells a broker how an investor wants a transaction handled. A
market order generally prioritizes execution, while a limit order sets a
price condition. Stop orders use a trigger and can behave differently from
what investors expect when prices move quickly.

Order availability and handling vary by broker and market conditions. No
order type guarantees a particular execution price or that an order will be
filled. Read the broker's current explanations and disclosures before using
an order type.
